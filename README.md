# UESXXI-LINF-SEMINARIO-PRACTICA-TP-GORRITI
# Sistema Informático para la Gestión de Turnos y Comunicación con Pacientes

## Proyecto

Proyecto académico desarrollado para la asignatura Seminario de Práctica de la Licenciatura en Informática – Universidad Siglo 21.

El proyecto propone el análisis, diseño y desarrollo de un sistema informático para la gestión de turnos y la comunicación con pacientes del Hospital Área Programa "Dr. Fernando Rocha", de Luis Beltrán, Río Negro.

## Objetivo

Contribuir a mejorar el acceso de la comunidad a los servicios de salud, facilitando la gestión de turnos y la comunicación entre la institución y sus pacientes.

## Tecnologías previstas

- Java
- MySQL

## Estado del proyecto

Etapa de análisis y definición de requerimientos.
